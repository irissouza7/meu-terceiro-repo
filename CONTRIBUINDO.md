# Como contribuir

Obrigado pelo interesse em contribuir com este projeto!

1. Crie uma branch a partir da `main` com um nome descritivo (ex.: `docs/ajusta-readme`).
2. Faça commits pequenos e com mensagens claras.
3. Abra um Pull Request explicando o que mudou e por quê.
4. Aguarde a revisão antes de fazer o merge.
